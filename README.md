
# Cash Sheet Mobile App

A simple, mobile-friendly web application for filling out travelling and meal expense reimbursement vouchers.

## Features

- Mobile-friendly interface
- Automatic total amount calculation
- Automatic grand total calculation
- Horizontal scrolling for the expense table on mobile devices
- Print two vouchers on a single A4 page
- Save or print vouchers as PDF
- No server or database required

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Use

1. Open the web application.
2. Enter the voucher and travel expense details.
3. Review the automatically calculated totals.
4. Click **Print / Save PDF**.
5. Select A4 paper size and Portrait orientation.
